# Bouncer Authorization Layer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a declarative authorization layer using AdonisJS Bouncer wired to the existing `PermissionResolver`, enabling `@can`/`@cannot` in Edge templates and `bouncer.authorize()` in controllers.

**Architecture:** Bouncer is a thin declarative layer that delegates all permission checks to the existing `PermissionResolver`. A request-scoped `PermissionResolver` middleware ensures a single cached instance is shared across all checks in one request. A named `permission` middleware gates route groups.

**Tech Stack:** AdonisJS v7, @adonisjs/bouncer, Edge.js, Japa (tests)

**Spec:** `docs/superpowers/specs/2026-03-19-bouncer-authorization-design.md`

- [ ] **Step 1: Create the middleware**

Create `app/middleware/permission_resolver_middleware.ts`:

```typescript
import PermissionResolver from '#services/permission_resolver'
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

declare module '@adonisjs/core/http' {
  interface HttpContext {
    permissionResolver?: PermissionResolver
  }
}

export default class PermissionResolverMiddleware {
  async handle(ctx: HttpContext, next: NextFn) {
    if (ctx.auth.user) {
      ctx.permissionResolver = new PermissionResolver(ctx.auth.user)
    }
    return next()
  }
}
```

import User from '#models/user'
import PermissionResolver from '#services/permission_resolver'
import { HttpContext } from '@adonisjs/core/http'

export const permission = Bouncer.ability(async (user: User, key: string) => {
  const ctx = HttpContext.get()
  const resolver = ctx?.permissionResolver ?? new PermissionResolver(user)
  return resolver.can(key)
})

import { test } from '@japa/runner'
import testUtils from '@adonisjs/core/services/test_utils'
import db from '@adonisjs/lucid/services/db'
import router from '@adonisjs/core/services/router'
import TenantService from '#services/tenant_service'
import { middleware } from '#start/kernel'

test.group('Permission middleware', (group) => {
  group.setup(async () => {
    const { default: PermissionsSeeder } = await import('#database/seeders/permissions_seeder')
    await new PermissionsSeeder(db.connection()).run()

    router
      .get('/__test/permission-gate', async () => {
        return 'OK'
      })
      .use([middleware.auth(), middleware.permission({ keys: ['vehicle:delete'] })])
  })
  group.each.setup(() => testUtils.db().withGlobalTransaction())

  test('admin passes permission middleware', async ({ client }) => {
    const { user } = await TenantService.createWithAdmin({
      companyName: 'Test Co',
      firstName: 'A',
      lastName: 'B',
      email: 'a@test.co',
      password: 'password123',
    })

    const response = await client
      .get('/__test/permission-gate')
      .withSession({ auth_web: user.id })
      .withCsrfToken()
    response.assertStatus(200)
    response.assertTextIncludes('OK')
  })

  test('user without permission is redirected to dashboard', async ({ client }) => {
    const { tenant } = await TenantService.createWithAdmin({
      companyName: 'Test Co',
      firstName: 'A',
      lastName: 'B',
      email: 'a@test.co',
      password: 'password123',
    })

    const UserModule = await import('#models/user')
    const User = UserModule.default
    const noRoleUser = await User.create({
      tenantId: tenant.id,
      firstName: 'C',
      lastName: 'D',
      email: 'c@test.co',
      password: 'password123',
    })

      .get('/__test/permission-gate')
      .withSession({ auth_web: noRoleUser.id })
      .withCsrfToken()
      .redirects(0)

    response.assertHeader('location', '/dashboard')

- [ ] **Step 3: Create the permission middleware**

Create `app/middleware/permission_middleware.ts`:

```typescript
import PermissionResolver from '#services/permission_resolver'
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

export default class PermissionMiddleware {
  async handle(ctx: HttpContext, next: NextFn, options: { keys: string[] }) {
    const resolver = ctx.permissionResolver ?? new PermissionResolver(ctx.auth.user!)
    const allowed = await resolver.canAny(options.keys)

    if (!allowed) {
      ctx.session.flash('error', "Vous n'avez pas accès à cette section.")
      return ctx.response.redirect().toRoute('dashboard.index')
    }

    return next()
  }
}
```
